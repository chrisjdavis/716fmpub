# Design context — 716FM

Authoritative brief for UI and motion work (including `/impeccable` and high-ambition surfaces). Update this when positioning shifts.

## Target audience

- **Primary:** People who already use **Last.fm-style scrobbling** and want **their own** canonical listening history—aggregates, timelines, and archive-style browsing—not a social feed.
- **Context:** Mostly **solo, screen-based** sessions (laptop or large phone): checking imports, reading month-level narratives, comparing windows, drilling into archive. Occasional late-evening use; not a live performance tool.

## Use cases

- **Onboarding / trust:** Connect account, run imports, see clear job status and errors until data feels “real.”
- **Orientation:** Dashboard home and **Explore (stats)** answer “what stands out in this period?” without requiring SQL or spreadsheets.
- **Time travel:** Scrub months, read period copy, jump to **archive** for the same month’s full history.
- **Operators / power users:** Same surfaces; favor **density, precision, and explicit labels** over playful empty states.

## Brand personality and tone

- **Personality:** **Archival broadcast**—confident typography, monospace labels and data, thin structural lines, restrained accent (brand) against neutral surfaces. Feels like a **well-designed logbook or station ledger**, not a consumer streaming app or a neon cyber-dashboard.
- **Tone:** Direct, slightly technical copy (`[NO DATA IN THIS WINDOW]` patterns are intentional). Warmth comes from **clarity and rhythm**, not from mascot voice or casual slang.
- **Motion:** **Purposeful and scarce.** When adding ambition (canvas, transitions, scroll effects), the “wow” should read as **signal made legible**—density, alignment, smooth handoff between months—not wallpaper particles or generic glow. Always respect **`prefers-reduced-motion`** with a calm static alternative.
- **Differentiation:** The product is remembered for **serious listening intelligence** and a **distinct visual system** (display + mono pairing, hairline grid, editorial section breaks)—not for maximal decoration.
